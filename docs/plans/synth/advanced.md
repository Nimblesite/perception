# Synth package: advanced synthesis delivery plan [SYNTH-ADVANCED]

## Advanced synthesis: core contracts [SYNTH-ADVANCED-CORE]

- [ ] Shared foundation exercised with invalid state, rate changes, asset generations, irregular partitions, unavailable models, cancellation and migration; dimensions, products, limits, finite data and model operators validated before preparation; format, processor state and asset lifetimes threaded through scalar and graph execution; producer queues, fault publication, latency, cancellation ownership and device starvation measured; seeds, applied parameter semantics and hashes kept across save/reload and relinking; wasm32 package execution, explicit backend unavailability, GC and ARC on supported hosts [STUDIO-ADVANCED-FOUNDATION].
- [ ] Schema changes round-trip old graphs and exercise missing and unknown fields; grain scheduling, body state and neural request descriptors carried through the public preparation and block interfaces, validation and observations; asset decoding, model execution and generated-asset jobs bounded, reusing worker ownership and cancellation with a dedicated typed model protocol [STUDIO-ADVANCED-BASELINE].
- [ ] Native Osprey formulas with proofs of their parsed bodies for windows, interpolation, modal transitions, waveguide tuning, energy accounting and controller mappings, checked for reference parity [STUDIO-ADVANCED-BASELINE] [SYNTH-DSP-PROOFS].

- [ ] `ChannelLayout` (ordered named channels; stereo default, 5.1/7.1/7.1.4/any N) declared in `graph.td` and carried by every port [SYNTH-GRAPH-CHANNELS].
- [ ] Layouts other than stereo on a track, `Grains` stereo summing and the `GraphClips` mono-to-stereo component [DAW-MODULAR-LAYOUT].
- [ ] Track and Master output layouts in the project file (`daw.td`); sample import keeps every source channel; the macOS device queue plays any layout CoreAudio offers [SYNTH-GRAPH-CHANNELS].
- [ ] Polarity (bipolar/unipolar) and control/audio-rate adapter nodes; hertz/normalised stays `Descriptors.fromControl`/`toControl` [SYNTH-ADVANCED-CORE-PORTS].
- [ ] Trigger events and mixed note, parameter and trigger events in one frame, in deterministic sample-offset order (same-frame parameter events and note on/off across exact partitions are already tested) [SYNTH-ADVANCED-CORE-PORTS].
- [ ] Decoding, table preparation, pool allocation and transform construction outside the audio callback; parallel routes aligned in preparation from each component's `Timings.latency`; a grain cloud added to a running graph starts without a restart (`GraphRebase.rebased`) [SYNTH-ADVANCED-CORE-RESOURCES].
- [ ] No allocation, blocking lock, file or network access, log formatting or observer callback in production render paths, by the realtime render-path rules [SYNTH-ADVANCED-CORE-RESOURCES] [SYNTH-ADVANCED-ORDER].

## Advanced synthesis: Perception Studio integration [SYNTH-ADVANCED-STUDIO]

- [ ] Perception Studio logo, original node styling, visible cables, inspector and bottom-docked closable keyboard preserved: `make -C src/toolchain/targets/tests synth` [SYNTH-ADVANCED-STUDIO].
- [ ] Module browser grouped by Sources, Grains, Physical, Spectral, Modulators, Effects, Utilities and Output with search and drag/click insertion (the native picker lists all 29 kinds as "Category · Title") [SYNTH-ADVANCED-STUDIO].
- [ ] Cable creation and removal, node movement and removal, Undo and Redo work for every advanced family [SYNTH-ADVANCED-STUDIO].
- [ ] Controls bound to applied parameter Signals; loading, failure, pending and rejected states shown on the affected control and node; an unavailable sample, model or plug-in is never a silent working instrument [SYNTH-ADVANCED-STUDIO].
- [ ] Macro controls mapped to typed parameters with declared ranges and smoothing in Perception Studio (the library part, `Macros` and `Smoothers`, is done) [SYNTH-ADVANCED-STUDIO].
- [ ] The same control commands exposed to Light Orchestra and phone adapters without networking or session state in the synth library [SYNTH-ADVANCED-STUDIO].
- [ ] Palette cards, observation Signals and saved patch files for every family; complete patches saved with resources, seeds, module versions, automation and controller mappings; incompatible or missing resources load explicitly [SYNTH-ADVANCED-STUDIO] [SYNTH-ADVANCED-DELIVERY].

## Advanced synthesis: granular [SYNTH-ADVANCED-GRAINS]

The sample-backed Grain Cloud slice is delivered before another family expands [SYNTH-ADVANCED-MILESTONES].

- [ ] Independent sample-source and scheduler graph factories with event and control modulation ports, Grain Scheduler and Sample Source in the module browser, typed modulation adapters, then granular presets before physical models; no Perception Studio-only synthesis path [SYNTH-ADVANCED-GRAINS-INTEGRATION] [SYNTH-ADVANCED-MILESTONES-NEXT].
- [ ] Source selection, waveform and position, density, duration, pitch, spread, seed and freeze controls in the existing inspector design, in meaningful units and bounded, with Perception Studio's original artwork [SYNTH-ADVANCED-GRAINS-INTEGRATION] [SYNTH-ADVANCED-MILESTONES-NEXT].
- [ ] Manual journey: add Grain Cloud, load a sample, connect stereo output, play several notes, edit controls, stop, remove the cable and node [SYNTH-ADVANCED-MILESTONES-NEXT].
- [ ] Keyboard and phone expression mapped to declared parameters, not instrument-specific commands [SYNTH-ADVANCED-GRAINS-INTEGRATION].
- [ ] Resource identity and scheduler state saved in patches; unavailable samples a visible recoverable error [SYNTH-ADVANCED-GRAINS-INTEGRATION].
- [ ] Distribution controls verified through the Perception Studio inspector (the clip journey covers 2,000 events at three seeds) [SYNTH-ADVANCED-GRAINS-SCHEDULING].
- [ ] A generated channel-policy model; the built-in source kept as an explicit selectable resource; loaded resource name, duration, rate and channel metadata, waveform and current source position shown through bounded observations [SYNTH-ADVANCED-GRAINS-IMPORT] [SYNTH-ADVANCED-MILESTONES-NEXT].
- [ ] An import-during-playback policy, shown clearly, with rendering never blocking while a replacement is prepared; content hash and a portable resolution strategy persisted, missing or changed files giving an explicit recoverable result [SYNTH-ADVANCED-GRAINS-IMPORT].
- [ ] `WaveImport.decode` journeys: every supported encoding, empty, truncated and oversized files, malformed chunk arithmetic, cancellation, stale completions, node removal, repeated replacement, Undo/Redo, missing resources, pitch consistency across sample rates [SYNTH-ADVANCED-GRAINS-IMPORT].
- [ ] Audio-queue starvation traced through producer, transport and device receipts (workload and timings recorded), then the producer bottleneck removed without weakening validation or hiding throughput failure behind a larger queue [SYNTH-ADVANCED-MILESTONES-NEXT].
- [ ] Seeded event traces and window and resampling oracles for reverse and single-frame sources, replacement, capture wrap, zero and maximum density and exhaustion; the shared sample and live kernel with independent pitch and scan, region boundaries, source retention and visible overload counts; Size, Density, Pitch, Scan, Capture, Freeze, waveform and region gestures driven through the Granular card and inspector with audio, applied state and screenshots compared, pitch and alias energy measured against the reference resampler, and a frozen pad and a time-stretched transient demonstrated with reproducible traces [STUDIO-ADVANCED-GRANULAR].

## Advanced synthesis: families [SYNTH-ADVANCED-PHYSICAL] [SYNTH-ADVANCED-TABLES] [SYNTH-ADVANCED-SPECTRAL] [SYNTH-ADVANCED-NONLINEAR] [SYNTH-ADVANCED-PHASE]

- [ ] Physical: activity and decay observations on the node rather than decorative waveforms; bowed and blown models, voice allocation, sample-rate state transfer, a mesh and transient-free time-varying coefficients [SYNTH-ADVANCED-PHYSICAL-INTEGRATION] [SYNTH-ADVANCED-PHYSICAL].
- [ ] Physical oracles and journeys: equations, boundary conditions, modal weights and ranges pinned for bars, plates, membranes, strings and tubes with impulse, tuning, decay and energy oracles; convergence failure, joint coupling, automation and material changes exercised before live use; Exciter, Modal Body, String and Tube driven through palette selection, conditional controls, pickup and contact gestures and mode and energy observations; struck metal, damped membrane, plucked, bowed and blown patches saved and reloaded after velocity, pickup, material and coupling changes; tuning and T60, decay and energy bounds and solver-exhaustion evidence collected [STUDIO-ADVANCED-PHYSICAL].
- [ ] Tables: prepared wavetable banks with explicit sample rate, table length, phase alignment and resource ownership; table import by FFT resynthesis; crossfaded level switching; Wavetable and Partial Bank cards and resource controls in Perception Studio [SYNTH-ADVANCED-TABLES].
- [ ] Spectral pitch: the 1 cent, 1 dB level and 1 dB ripple acceptance held on plucks and a voice-like source (sines pass at 16 and 48 kHz in `wave_journeys.ospml`) [SYNTH-SPECTRAL-PITCH-EFFECT]; transient handling and time stretching with their own latency contract [SYNTH-ADVANCED-SPECTRAL-MODULES].
- [ ] Spectral morph: cross-frame peak tracking for inharmonic sounds ([failure modes](../../specs/synth/dsp.md#failure-modes)) [SYNTH-SPECTRAL-MORPH].
- [ ] Real-time autotune: YIN-style fundamental with confidence, snapping to key, scale or the timeline's notes, retune speed, amount and humanise, formant-preserving FFT correction, unvoiced frames dry, bounded per-hop work without allocation, declared latency; native Osprey formulas; tests for a 30-cent-flat vibrato line, glide timing, unvoiced noise and block-split invariance [SYNTH-SPECTRAL-AUTOTUNE].
- [ ] Spectral: shared analysis feeding freeze, morph and resynthesis, spectral ports, tail flushing, pitch and time beyond integer-bin shifts, a CPU budget, and displays driven by bounded observer snapshots, never analysis on the UI thread [SYNTH-ADVANCED-SPECTRAL].
- [ ] Delay, Diffuser, Feedback Matrix, Waveshaper, Frequency Shifter and Reverb exposed in Perception Studio; oversampling beyond 2×; delay and matrix as separate nodes; pitch-shifted feedback [SYNTH-ADVANCED-NONLINEAR].
- [ ] Phase and operator modules with editable routing in Perception Studio, modulation depth and scaling adapters, antialiased [SYNTH-ADVANCED-PHASE].

## Advanced synthesis: learned, neural and combined [SYNTH-ADVANCED-LEARNED] [STUDIO-ADVANCED-NEURAL] [STUDIO-ADVANCED-HYBRID]

- [ ] App controls preview, apply and reject fitted parameters without overwriting a working patch silently (`Fitting` and `FitReports` exist) [SYNTH-ADVANCED-LEARNED].
- [ ] Neural fixtures and backend: redistributable RAVE, DDSP, codec and text-to-audio models selected independently with exact hashes, operator and runtime compatibility, licences and training-data provenance recorded; load, warm-up, execution distribution, memory, hop and lookahead and cancellation benchmarked on Windows and the other target hosts; the backend (ONNX export or TorchScript) chosen only after the models run with bounded operator support [STUDIO-ADVANCED-NEURAL].
- [ ] Neural lifecycle: manifest rejection, worker loss, late replies, shape errors and codebook bounds exercised through typed effects, with history across irregular blocks [STUDIO-ADVANCED-NEURAL].
- [ ] RAVE transfer and DDSP Audio/MIDI with latency-compensated mixing and pitch confidence; real codec encode and decode fixtures run; generated assets validated with cancellation, preserving prompt, duration, seed and model revision; Preview and Insert exercised independently [STUDIO-ADVANCED-NEURAL].
- [ ] Neural UI: model selection, capability and error display, latent or harmonic/noise controls, codec inspection and generation, with missing assets, replacement, stale results, cancellation and save/reload; genuine audio, held-out measurements and lifecycle evidence per capability; backend nondeterminism recorded in replay metadata [STUDIO-ADVANCED-NEURAL].
- [ ] Combined body-dependent contacts: analytic controller, then a learned scheduler or texture decoder with energy-constrained forces, so initial body state changes future contact traces only with Interaction enabled; the native energy model and its checked bound proved against the production transition; the analytic baseline measured before training [STUDIO-ADVANCED-HYBRID].
- [ ] Joint sound analysis (grain dictionary, contact envelope and material from reference audio) and text-directed contact trajectories, each with its own reconstruction, validity and edit evidence [STUDIO-ADVANCED-HYBRID].
- [ ] The Combined module's Texture, Material, Body memory, Interaction and Energy controls, contact map, timeline, energy inspector, numeric and keyboard alternatives and controller selection, compared under matched loudness and latency with routed grains, open-loop contacts, analytic feedback and learned control without energy features; negative results retained [STUDIO-ADVANCED-HYBRID].
- [ ] Resampling quality thresholds, membrane and tube reference models, runtime and redistributable model selection, platform memory and performance limits and the hybrid training dataset resolved by their named experiments [STUDIO-ADVANCED-DELIVERY].

## Advanced synthesis delivery plan [STUDIO-ADVANCED-PLAN]

Acceptance ([SYNTH-ADVANCED-VERIFY], the [acceptance matrix](../../specs/synth/advanced.md#acceptance-contract-synth-advanced-verify)) and handoff ([SYNTH-ADVANCED-DELIVERY]). Results are recorded for the stated workload, backend and host; a module is marked production only with measured evidence.

- [ ] Loaded end-to-end patch journeys with repeated same-kind instances, fan-out, modulation, removal, undo, save/load and failures [SYNTH-ADVANCED-VERIFY-CORRECTNESS].
- [ ] Physical tuning, decay and energy bounds, rate changes and extreme parameters; wavetable and additive phase continuity, modulation and table replacement; spectral reconstruction, overlap/add normalisation, latency, freeze/release and transport discontinuities [SYNTH-ADVANCED-VERIFY-CORRECTNESS].
- [ ] Nonlinear and phase outputs compared with independent higher-quality references under level and latency matching; nonfinite data, malformed resources, invalid units, stale revisions, overflow and unavailable resources injected, with explicit failure and preserved prior state [SYNTH-ADVANCED-VERIFY-CORRECTNESS].
- [ ] Allocation, locking and unbounded operations instrumented in the compiled native callback path; worst callback time, queue starvation, CPU, memory and latency measured on named hardware with declared workloads [SYNTH-ADVANCED-VERIFY-REALTIME].
- [ ] Slow or detached Signal subscribers never stall rendering; observations keep coherent revisions and sample positions [SYNTH-ADVANCED-VERIFY-REALTIME].
- [ ] Live graph and resource swaps, state transfer, crossfade policy, tail disposal and failure rollback verified [SYNTH-ADVANCED-VERIFY-REALTIME].
- [ ] Reference and offline availability separated from verified realtime capability in public descriptors and documentation [SYNTH-ADVANCED-VERIFY-REALTIME].
- [ ] Headless and windowed journeys that add, connect, edit, play and remove every advanced module; screenshots against Perception Studio's visual style; real mouse dragging, cable deletion, keyboard docking, window resizing and accessible controls; window screenshots and journeys verified on an unlocked desktop [SYNTH-ADVANCED-VERIFY-PLATFORMS] [STUDIO-ROUTING-DELIVERY].
- [ ] Native and canvas interfaces exercised with loaded headless and windowed journeys, screenshots, actual audio output and level-matched listening examples for each family (patch, resource and seed metadata); cross-platform availability with explicit platform limits [STUDIO-ROUTING-DELIVERY] [SYNTH-ADVANCED-VERIFY-PLATFORMS].
- [ ] macOS and Windows integrations verified with device and backend differences documented; browser and mobile builds through their supported hosts, reporting unsupported modules, resource limits and latency instead of substituting another algorithm [SYNTH-ADVANCED-VERIFY-PLATFORMS].
- [ ] Each module's ports, units, scaling, defaults, state and reset semantics, latency, capacity and supported rates and channels documented (the module reference) [SYNTH-ADVANCED-DELIVERY].
- [ ] Code, specifications, patches and test evidence linked through the section IDs here, and this checklist reconciled with [Synthesis.md](../../specs/synth/graph.md) [SYNTH-ADVANCED-DELIVERY].
- [ ] Experimental or production status marked from measured evidence; remaining limitations recorded; task-owned temporary processes and artifacts removed [SYNTH-ADVANCED-DELIVERY] [STUDIO-ROUTING-DELIVERY] [STUDIO-ROUTING-WRAP-UP].
- [ ] The shipped songs play every family (granular and spectral morph are missing today); a test opens each song and checks every family is present [SYNTH-SHOWCASE].
- [ ] `@osprey/synth` coverage to 100% (63.4%, 2,650 of 4,180 lines) through loaded journey tests per family [SYNTH-ADVANCED-VERIFY] [STUDIO-ROUTING-VERIFY-COVERAGE].
- [ ] Static analysis, package coverage, CI preparation, root CI and the duplication gate green, with one validated push under the TMC lock and its CI inspected [STUDIO-ROUTING-DELIVERY] [SYNTH-ADVANCED-DELIVERY].
